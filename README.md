📌 CalciSketch — Handwritten Equation Solver

Overview:
CalciSketch is a Python-based GUI application that allows users to draw mathematical equations by hand, process the input using image recognition, and evaluate the result in real time.

Features:
Interactive whiteboard for freehand drawing

Equation recognition and parsing

Save/load sketches for later use

Integrated calculation engine

Tech Stack:
Python, CustomTkinter, Tkinter
Ollama's Mistral Model,Gemini API
